# CVPR Negative Results and Rejection Ledger

Date: 2026-11-02

This ledger preserves lessons that must prevent repeated work. It intentionally
contains no completed task history.

Oracle-control Delta-IoU/Delta-MSE and strict-locality results are current
positive evidence. The predicted-control blockers below are a separate,
deployable track and must not be used to negate the oracle-control result.

## Required Checks Before Reopening a Rejected Route

1. Name the new mechanism that changes the causal bottleneck, not just its budget.
2. Pass the atom proxy and canonical consistency contract from `fptodo.json`.
3. Match cases, seeds, preprocessing, evaluator, output contract, parameters, and
   training exposures against a control.
4. Improve the target metric on calibration and a disjoint holdout.
5. Preserve all hard safety and downstream consumer gates.
6. Record the exact stop condition and evidence path in the experiment report.
